## Import Priority

Assets should be imported and generated in this order:

### Priority 1: Critical Path (Required Before Production)

1. **AUDIO-001** — Main audio track (determines total duration, enables sync)
2. **FONT-001, FONT-002, FONT-003** — Typography (used throughout)
3. **FIG-001** — Basic human silhouette (used in all movements)
4. **MASK-001** — Basic mask (used in Movements I-IV)

### Priority 2: Movement-Specific (Required Per Movement)

5. **ENV-001 through ENV-005** — Environments (one per movement)
6. **Movement-specific figures, masks, mechanical elements**
7. **Movement-specific textures and effects**

### Priority 3: Enhancement (Improves Quality, Not Blocking)

8. **Reference images** — Guide style but not required for generation
9. **Texture source images** — Can be replaced by fully procedural textures
10. **Additional variants** — Multiple versions of assets for variety

## Version Control

Generated assets are tracked in version control (git) only as scripts and parameters — not as binary files. Binary assets (PNG frames, rendered environments) are stored outside version control and referenced by hash.

```
# In version control:
scripts/generate_mask.py          # Script that generates masks
config/mask_parameters.json       # Parameters for mask generation
config/movement_01_assets.json    # Asset manifest for Movement 1

# Outside version control:
assets/generated/masks/*.png      # Rendered mask images (gitignored)
assets/output/frames/*.png        # Rendered frames (gitignored)
```

This approach keeps the repository small while enabling full reproducibility — any asset can be regenerated from its script and parameters.
